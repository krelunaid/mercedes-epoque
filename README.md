# Mercedes Époque

Noleggio di Mercedes classiche e moderne. Interfaccia in italiano.

## Cosa c’è

- Collezione: Gullwing, Roadster, 190 SL, Pagoda, 300 SEL 6.3, AMG GT, SL 63, G 63
- Prenotazioni con calendario e assicurazione
- Preferiti e garage
- Calendario eventi **ufficiali** (Salon Privé, Goodwood Revival, Classics & Coffee, Auto e Moto d’Epoca) con link ai siti degli organizzatori
- Accesso con Google o X

## Avvio

```bash
npm install
npm run dev
```

Poi apri l’indirizzo indicato dal terminale.

```bash
npm run build
npm run typecheck
```

## Stack

TanStack Start, React, Tailwind, Better Auth, Postgres (Neon o PGLite in locale).
